# Behavioral Atoms H3 Boundary Decision v0.7

H3 is admitted only as a private, explicit static-evaluation slice. The default
compiler remains H2. Neither a family label nor a trigger word can activate H3;
callers must select the H3 registry and provide atom-specific semantic signals.

`secret_boundary` adds evidence authority and owner-bound scope beyond H2
redaction. `evidence_ladder` adds completeness and freshness accounting beyond
the H2 ship gate. Each retains its H2 atom as a typed dependency.

The two eligible advisory transplants are deliberately non-duplicative:

- release receives an authority gate for sensitive evidence; and
- security/privacy receives a completeness ladder for quality evidence.

The frozen v0.7 fixtures cover a complete combined case, a negative case, and
both ambiguous failure boundaries. Provider execution, cross-skill composition,
public projection, routing, admission, promotion, installation, and release are
closed. H3 atoms render only to the private `advisory_trace` target.
