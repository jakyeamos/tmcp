# TMCP 0.5.2 Archive Install Fix

TMCP 0.5.2 is a focused patch release for the central runtime distribution
path. Deterministic release archives contain files below `tmcp/` but do not
necessarily contain a separate directory member for that root. The runtime
manager now validates that archive shape correctly while preserving digest
pinning, path-containment, and symlink rejection.

The 0.5.1 central-runtime package remains available as a retained rollback
version, but 0.5.2 is the supported release for archive installation.
