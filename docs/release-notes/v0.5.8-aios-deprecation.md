# TMCP 0.5.8: AIOS Deprecation Boundary

TMCP 0.5.8 makes `AIOS_ROOT` inert by default. Temporary legacy AIOS adapter
execution now requires both `TMCP_ENABLE_DEPRECATED_AIOS_ADAPTER=1` and a valid
`AIOS_ROOT`. Standalone TMCP behavior remains unchanged.

This release also makes nested Git runtime fixtures hermetic by removing
inherited `GIT_*` operation state. That prevents parent executors and commit
hooks from redirecting fixture commits into a locked or unrelated parent
index.

Verification covers disabled-by-default status and explicit dispatch,
compatibility activation with both gates, standalone behavior, ambient Git
operation isolation, the full platform matrix, and deterministic packaging.
