# TMCP 0.5.6 Native Git Provenance Inference

TMCP 0.5.6 supports both Codex native marketplace behaviors observed locally:
checkouts that include `.codex-marketplace-install.json` and clean Git
checkouts that rely on the canonical remote, detached release tag, and exact
source commit. Both forms remain Codex-owned surfaces during runtime sync.

The manager rejects a native candidate when the checkout root, Git remote,
release tag, source revision, or non-generated Git state disagrees with the
active runtime. Generated package copies continue to use deterministic content
and skill digests.
