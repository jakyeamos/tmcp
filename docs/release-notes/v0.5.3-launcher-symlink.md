# TMCP 0.5.3 Symlinked Launcher Fix

TMCP 0.5.3 fixes launcher execution through the versioned central runtime's
`active` symlink and the compatibility alias used by existing repository MCP
configuration.

The Node entrypoint now compares resolved paths before starting the Python CLI.
This preserves the existing relative launcher contract while making atomic
runtime cutovers observable through `doctor`, `status`, and `list-tools`.
The release includes a subprocess regression test for symlinked invocation.

TMCP 0.5.2 remains available as the previous runtime version until the next
retention review.
