# TMCP 0.5.4 Runtime Provenance

TMCP 0.5.4 closes the remaining mutable-marketplace risk in the central local
runtime. The Claude marketplace catalog now points at the immutable `v0.5.4`
release tag instead of `main`, and the runtime manager validates that new
packages carry the matching release-tag ref.

The installed runtime manifest records the marketplace ref alongside the
release, Codex build, source commit, package digest, and skill digest. Generated
Codex and Claude caches remain consumers of the active runtime and are replaced
only after staged parity checks. The retained 0.5.3 runtime remains readable for
offline rollback, including its historical `main` marketplace metadata; the
legacy exception does not weaken validation for new releases.

Verification includes modern unpinned-package rejection, legacy rollback
compatibility, package contract checks, reproducible archive creation, clean
install and launcher smoke tests, native marketplace refresh, and a two-way
runtime rollback.
