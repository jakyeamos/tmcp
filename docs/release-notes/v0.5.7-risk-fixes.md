# TMCP 0.5.7 Rubric Coverage and Launcher Mode Fixes

TMCP 0.5.7 fixes two small distribution risks found during the central-runtime
migration:

- profile coverage terms represented as Python tuples are now matched by the
  expert-review evidence gate, so missing general-profile coverage is reported
  only when it is actually missing;
- `scripts/tmcp_launcher.mjs` is shipped as an executable file, while the
  documented `node` invocation remains supported.

The patch is intentionally limited to review-contract correctness and launcher
entrypoint permissions. Runtime version pinning, native marketplace provenance,
generated-cache parity, and rollback behavior remain unchanged from 0.5.6.
