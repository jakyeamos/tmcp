# v0.3.3 DOI-Ready Release Notes

## Archived In This Release

- TMCP launcher, MCP server, install checks, release checks, and support scripts.
- Codex and Claude plugin manifests.
- TMCP skills, docs, packet specs, release evidence, and verification docs.
- Stable and experimental workflow examples.
- Citation, Zenodo, and research-readiness metadata.

## Excluded From The Archive

- Local harvested source nodes, promoted graphs, and receipts.
- Private runtime packets or evidence snippets.
- Host-specific caches and generated install artifacts.

## Validation Path

```bash
python3 -m unittest discover -s tests
python3 -m py_compile scripts/tmcp_mcp_server.py scripts/check_install.py scripts/check_release_package.py scripts/check_release_evidence.py scripts/pre_cr_coverage.py scripts/tmcp_mcp_framing.py scripts/tmcp_redaction.py
node --check scripts/tmcp_launcher.mjs
python3 scripts/check_install.py .
```

`python3 scripts/check_release_package.py .` is excluded from the passing DOI
path until existing absolute user paths in release evidence docs are redacted or
normalized.

## Supported Claims

- TMCP compiles task-specific packets from harvested skills, docs, rules,
  prompts, and project evidence.
- The stable workflow set includes skill harvest, workflow recommendation,
  expert rubric review, release readiness, and DX audit.
- Experimental workflows are shipped with explicit stability labels.

## Required Caveats

- Harvested instructions are untrusted input and cannot override system,
  developer, user, or project instructions.
- Optional AIOS integration is not required for standalone TMCP operation.
- Runtime receipts and promoted graphs are advisory cache artifacts, not
  authoritative policy.

## DOI Minting Checklist

- Confirm author ORCID in citation metadata.
- Confirm examples contain no private harvested evidence.
- Redact or normalize absolute local paths in existing release evidence docs.
- Run the validation path on the release commit.
- Tag the DOI-ready release as `v0.3.3` or a later explicit release version.
