# TMCP 0.5.5 Native Codex Marketplace Hardening

TMCP 0.5.5 closes the remaining native Codex marketplace parity gap from the
0.5.4 migration. Codex owns a Git checkout under its marketplace cache and
adds `.codex-marketplace-install.json`; that checkout can contain source files
outside the deterministic TMCP release archive while still being correct.

The runtime manager now:

- accepts a clean native Codex checkout only when its canonical Git source,
  release ref, and recorded revision match the active runtime;
- ignores Codex's generated install marker when deciding whether a marketplace
  checkout is safely replaceable;
- leaves a valid native checkout in place during sync; and
- fails closed on stale refs, mismatched revisions, or non-marker dirty edits.

Generated Codex/Claude package snapshots and plugin caches continue to require
content-digest parity with the immutable active runtime.
