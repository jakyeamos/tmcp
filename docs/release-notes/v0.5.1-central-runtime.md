# TMCP 0.5.1 Central Runtime

TMCP 0.5.1 adds a local distribution boundary for workspaces that use the
package from more than one agent host. `scripts/tmcp_runtime.mjs` installs a
verified release archive into an immutable version directory, records the
release/commit/content/skill digests, syncs generated plugin surfaces, and
switches an explicit active pointer only after validation. The previous active
version remains available for offline rollback.

The public MCP tools, CLI aliases, packet schemas, and portable relative
launcher remain compatible with 0.5.0. Repository-local AGENTS files, domain
skills, evidence, and project instructions remain local overlays. Existing
absolute repository MCP configs may continue using the generated compatibility
alias until they are migrated to a host-native central-runtime reference.

The release artifact must be built from the verified tagged commit. Its exact
SHA-256 is reused in the GitHub Release and MCP Registry metadata.
