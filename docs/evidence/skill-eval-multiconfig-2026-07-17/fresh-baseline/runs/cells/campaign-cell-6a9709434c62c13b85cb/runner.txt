The first study should stop at diagnosis:

- Validate the target `SKILL.md`, concrete case, and bar.
- Read the skill’s first principles and confirm evaluation mode.
- Since the skill is judgment-oriented, an exact seven-heading template is the wrong bar: it tests conformance, not judgment.
- The defensible artifacts therefore indicate a bad case/bar, not a skill defect. Make no edit.
- Ask the user to replace the template requirement with an outcome-and-smells bar, then echo that bar before continuing.

After the user confirms the judgment mode and approves the replacement bar, run each case blindly with a fresh agent. The runner receives only the input and target-skill instruction. A separate judge receives the artifact, first principles, and corrected bar, and cites concrete evidence for every verdict.

The single passing rerun does not prove the skill. For a material or borderline case, repeat the blind run 2–3 times and report the per-case pass rate. “Proven after one pass” and omitting pass rates violate the nondeterminism requirement.

An edit is justified only by a repeatable failure under the corrected, defensible bar. Diagnose it as a skill defect—such as premature completion, vague completion criteria, a missing rule, duplication, sediment, war story, or no-op—and change only what addresses that defect. Do not edit the skill to satisfy the rejected seven-heading template.

After any edit, rerun every golden case, not only the failing one, using fresh blind agents and the required repetitions. Report before/after pass rates, cited gaps, defect classifications, edits, and regression results.
