Before any edit, stop and confirm the skill’s first principles and that it is judgment-oriented. The exact seven-heading template is a conformance bar applied to a judgment skill, so defensible artifacts failing solely on that basis diagnose a bad golden-case bar—not a skill defect. Replace it with an outcome-and-smells bar the evaluator can apply without prescribing the answer’s structure.

After the user confirms that mode and approves the replacement bar, rerun blindly with a fresh runner that sees only the case input and target skill. Judge the artifact separately against the skill’s confirmed principles and corrected bar, citing concrete evidence.

One passing rerun does not prove the skill. Because the case matters and the conclusion is categorical, run it 2–3 times and report a per-case pass rate, including cited gaps for any misses. The report that declares success after one pass and omits rates is itself incomplete evaluation, not evidence of a proven fix.

An edit is justified only if repeated failures under the defensible judgment bar show the skill fails to drive behavior it claims to require. Map that failure to a specific authoring defect—such as a missing rule, vague completion criterion, or premature completion—then make the smallest targeted revision under the write-skills principles. Do not edit to enforce the discarded seven-heading template.

Finally, re-evaluate every case, not just the originally failing one, with fresh blind runs and report before/after pass rates. Accept the edit only if all cases meet the agreed rate bar; otherwise report either the remaining skill defect or that the case/bar is not expressible by the skill.
