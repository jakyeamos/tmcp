No. One passing evaluation run is evidence, not proof—especially if it covers only one case or one execution.

Before making a durable guidebook claim:

1. Confirm the run was valid: the runner was fresh and blind, saw only the case input, and never saw the expected outcome or grading bar.
2. Inspect the live checkout for leaked artifacts or context and clean any contamination.
3. Run a broader sweep using multiple representative golden cases, including likely edge and failure cases. Use one fresh, context-free runner per case.
4. Have judges assess each artifact independently against that case’s stated bar and the skill’s first principles—not against other artifacts or a vague numeric score.
5. Record pass rates and cite concrete gaps. Map every failure to a defensible skill defect; revise the bar instead when the failure exposes a bad evaluation standard.
6. Edit the skill only from those diagnosed defects, then rerun the entire sweep blind with fresh agents.
7. Make the guidebook claim only if the re-evaluation shows consistent success across the representative sweep. Scope the claim to exactly what those cases support, and retain the before/after evidence.
