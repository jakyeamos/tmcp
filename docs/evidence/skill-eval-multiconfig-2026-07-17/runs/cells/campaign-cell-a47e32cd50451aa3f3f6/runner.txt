Revise the target skill by replacing “make it good” with a concrete, observable completion criterion derived from the skill’s first principles and the failed case’s bar. Change only that criterion; do not add explanatory bulk, duplicate rules, or encode the golden answer.

Then:

1. Blind-run all three cases again, not only the failed one, using one fresh, context-free agent per case. Each runner sees only its case input and the target skill.
2. After every run, check the live checkout and clean any leaked changes.
3. Have separate fresh judges grade each artifact using only the artifact, that case’s bar, and the skill’s first principles.
4. Require evidence-backed verdicts for every part of each bar.
5. Re-run important or borderline cases 2–3 times and report pass rates.
6. Continue revising and re-evaluating all cases until every case clears its rate bar, or report that the skill structurally cannot express a case.

The final report should show each case’s before/after pass rate, cited gap, the “vague completion criterion” diagnosis, the exact criterion change, and the full re-evaluation result.
