No. A single green run may be agent nondeterminism, not reliable skill behavior.

Before making a durable guidebook claim:

1. Re-run the same case blindly 2–3 times, using a fresh, context-free agent for every run.
2. Give each runner only the case input and the target skill—never the bar, expected outcome, prior artifacts, or evaluation purpose.
3. Grade each artifact separately against the skill’s first principles and the case bar, citing concrete evidence.
4. Report the pass rate, not merely the best result.
5. If any run fails, determine whether the cause is a skill defect or a bad evaluation bar. Fix only genuine skill defects.
6. After any edit, re-run every golden case to check for regressions.

Only consistent passing across the relevant cases supports a durable claim that the skill works. A 1-of-1 result supports, at most, “it passed once.”
