# TMCP system map

This is a proposal-stage system map for TMCP. The root Compass, runtime
documentation, schemas, skill contracts, and release evidence remain
authoritative.

## Load order

1. Read `CONTEXT.md` for product surfaces and coverage gaps.
2. Read `_meta/schema.md` before adding cards.
3. Use `objects/_index.md` to choose a bounded noun slice.
4. Verify source citations before marking a card verified.

No `processes/` or `effects/` shelf exists yet.

## Authority

- `.project-compass/` owns TMCP intent, child purpose, quizzes, and alignment.
- This map owns only proposed structure and citations.
- Experimental workflows and disabled integrations remain explicitly labeled;
  they are not promoted by this map.
